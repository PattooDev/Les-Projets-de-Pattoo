# Cricut découpe — présentation Facebook

🔧 **Nouveau chantier : faire travailler une Cricut Maker sous Linux !**

J'ai lancé un projet expérimental pour étudier le pilotage d'une Cricut Maker originale depuis Deepin 25, sans dépendre nécessairement de Cricut Design Space.

Première étape franchie : Linux reconnaît la machine et son port USB est accessible. Nous avons aussi commencé à étudier les projets libres **Inkcut** et **FreeKnife**, ainsi que les travaux d'autres passionnés qui analysent le protocole Cricut.

L'idée n'est pas de tout réinventer : nous voulons réutiliser ce qui existe et développer uniquement les éléments manquants. Pour l'instant, la communication et la découpe réelle ne fonctionnent pas encore : le protocole propriétaire reste le principal obstacle. Les premiers essais seront des simulations sans aucun risque pour la machine.

Curieux, bricoleurs, développeurs Linux ou utilisateurs de Cricut : vos expériences et vos pistes sont les bienvenues !
