Deepin • Eww v0.4.0

PatDesk

Tableau de bord système léger pour Deepin Linux : CPU, RAM, disques, températures, réseau, alertes, état des mises à jour et raccourcis pratiques.

  • Alertes visuelles système
  • Raccourcis PatSecure, Terminal et Fichiers
  • Nouveaux raccourcis vers le site Les projets de Pattoo et ChatGPT
  • Fenêtre stabilisée sous Deepin/KWin : visible sur le bureau, mais derrière les applications
  • Repositionnement automatique sur l'écran DP-0 avec wmctrl lorsqu'il est disponible
  • Statut des mises à jour via le cache APT local
  • Fonctionnement local, sans télémétrie
